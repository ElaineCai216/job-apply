# 求职自动填报系统（Job Auto-Fill System）

一个"**你来确认、我来填报**"的求职申请工作流。你提供投递链接、目标职位、内推码和原始简历，我负责：**按岗位需求调简历侧重** → 解析档案 → 自动填写表单 → 截图给你预览 → **你确认后我才提交** → 记录到投递台账。

## 核心原则（写死的规则）

1. **提交前必确认**：未经你明确说「确认 / 提交」，我绝不点击最终提交按钮、绝不发送邮件。
2. **关键信息透明**：预览时我会列出每一项填了什么（邮箱、电话、简历附件、内推码、薪资期望等），以及哪些字段留空/需要你拍板。
3. **全程留痕**：每次申请都在 `apps/tracker.md` 记一笔，截图存档可回看。
4. **元数据我来记**：你只给链接，公司名/职位/渠道/投递日期/回音更新全部由我识别并记录，你只负责确认。

## 工作流（每次投递）

### Step 0 · 输入（最小化）
你**只需要给我投递链接**（可附带想投的职位方向、内推码、原始简历）。
- 公司名、职位、渠道/ATS 等元数据：我**打开链接自动识别**并记录，你不需要提供
- 投递日期：在最终提交那一刻由我记录（不提前、不补记）

### Step 1 · 识别并建档
我打开你给的链接，自动识别：公司名、职位、渠道/ATS（Greenhouse / Lever / Ashby / Workday / LinkedIn / BOSS / 邮箱等），
写入 `apps/tracker.md` 与该公司的记录文件夹；同时读取你的简历 → 整理成结构化 `profile/profile.json`。
- 识别结果先给你核对一眼，再进入下一步
- 简历档案首次生成后给你过目，确认无误再启用

### Step 2 · 简历适配（按 JD 调侧重）
我读岗位要求（JD）→ 按 `docs/简历针对性调整SOP.md` 调整你简历的侧重：重写摘要定位句、把与 JD 最相关的经历/成果提前、按 JD 权重重排技能，只改呈现不改事实。
- 交稿前给你一份「改了什么、为什么改」的对照说明
- 你确认后定稿为 `姓名-公司-职位-定制vN`，原件与定制版分开存档
- 之后投递附件与台账「简历版本」都指到这版

### Step 3 · 打开并填写
我用应用内浏览器打开投递链接，按页面字段从档案取数填入：
- 常规字段（姓名/邮箱/电话/城市/签证状态等）→ 自动填
- 必答开放题（为什么选我们 / 期望薪资 / 到岗时间）→ 起草草稿，标注【待你确认】
- 简历附件 → 使用你指定的简历版本
- 内推码 → 填到你给的地方

### Step 4 · 预览（确认门）
填完后**不提交**，我给你：
1. 每一页表单的截图（可直接查看）；
2. 字段摘要表：填了什么 + 哪些空着 + 哪些是【待你确认】的选项；
3. 需要你拍板的问题（例如期望薪资填多少、是否勾选「需要工签支持」）。

你说「确认」→ 我继续；你说改哪里 → 我改完再给你看一遍。

### Step 5 · 最终提交
你确认后，我才点击提交/发送，并在 `apps/tracker.md` 记录：公司、职位、链接、内推码、简历版本、日期、状态。

### Step 6 · 跟进
状态变化（HR 回应 / 笔试 / 面试 / 拒信）随时更新台账；需要时我帮你设跟进提醒。

## 覆盖的投递形态

| 形态 | 说明 | 确认方式 |
|---|---|---|
| ATS 网申（Greenhouse / Lever / Ashby / Workday 等） | 多步表单 | 每页截图 |
| LinkedIn Easy Apply | 快速投递 | 提交前截图 |
| 邮箱投递（HR 邮箱） | 我起草邮件正文 + 附件简历 | 先展示邮件全文 + 附件，确认后再发送 |
| 国内平台（BOSS / 拉勾 / 智联等） | 站内沟通 | 按平台流程，截图确认 |
| 内推 | 使用你给的内推码 / 内推链接 | 单独跟你确认内推信息 |

## 需要你配合的点

- **首次登录**：需要登录的站点（LinkedIn、BOSS 等），你在应用内浏览器里登录一次即可，之后我复用会话。
- **拍板选项**：期望薪资、到岗时间、是否需要工签等，我会列出来让你选，不会自作主张。
- **简历版本**：原始简历请给我**可编辑版**（Word/Markdown）更利于做针对性调整；只有 PDF 也可以，我会给出可替换文本块。原件永远保留，定制版会先给你确认。

## 二期规划（脚本化加速）

`automation/` 将逐步加入 Playwright 适配器（Greenhouse / Lever / Ashby / Workday…），把高频 ATS 表单的填写脚本化。但脚本同样遵守硬规则：**提交前必须人工确认**，确认门不变。
