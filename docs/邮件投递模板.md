# 邮件投递模板（中文 / 英文）

> 用于 HR 邮箱投递、内推邮件、跟进邮件。发送前我会把**主题 + 正文 + 附件版本**一起给你确认，你确认后再发。

## 使用规则

- **语言**：投大陆公司用中文；投香港/海外或 JD 为英文用英文。
- **附件命名**：`姓名-公司-职位-简历.pdf`（不要用「简历.pdf」「resume final(2).pdf」这种）。
- **附件版本**：用针对该 JD 优化过的版本（中文版/英文版），不要发通用版。
- **正文长度**：300 字以内 / 150 words 以内，HR 只扫几秒。
- **必含信息**：应聘岗位、姓名、相关经验一句话、可到岗时间、联系方式。
- **不要**：不要群发口吻、不要附件里放身份证/照片（除非公司要求）、不要写「尊敬的领导」这种过时称呼。

## 一、中文投递模板

**主题**：应聘{{职位}}｜{{姓名}}｜{{年限}}年{{方向}}经验

**正文**：

```
{{称呼，如：HR 您好 / 招聘负责人您好}}：

我是{{姓名}}，看到贵司在招「{{职位}}」，想申请这个岗位。

我有{{年限}}年{{方向}}经验，目前在{{现公司/学校}}{{一句话核心职责}}。与岗位最相关的三点：
1. {{与 JD 高度相关的成果，带数字}}
2. {{与 JD 高度相关的技能/项目}}
3. {{与 JD 高度相关的经历}}

我{{到岗时间，如：可在两周内到岗 / 目前在职，通知期一个月}}，简历见附件（{{简历版本}}）。
期待有机会进一步沟通，谢谢！

{{姓名}}
{{电话}} ｜ {{邮箱}} ｜ {{LinkedIn/GitHub if any}}
```

**内推版加一句**（放在第一段后）：

```
我是通过{{内推人姓名}}{{与你的关系，如：学长 / 前同事}}了解到这个岗位的，内推码：{{内推码}}。
```

## 二、英文投递模板

**Subject**: Application for {{Position}} — {{Name}} ({{Years}} yrs {{Field}})

**Body**:

```
Dear Hiring Team,

I'm writing to apply for the {{Position}} role at {{Company}}. I'm a {{Field}} professional with {{Years}} years of experience, currently {{Current Role}} at {{Current Company}}.

Three highlights most relevant to this role:
1. {{Achievement with numbers, mirroring the JD's keywords}}
2. {{Skill or project the JD emphasizes}}
3. {{Relevant experience or domain knowledge}}

I'm available to start {{availability}} and have attached my CV ({{CV version}}).
I'd welcome the chance to discuss how I can contribute.

Best regards,
{{Name}}
{{Phone}} | {{Email}} | {{LinkedIn}}
```

**Referral line**（如适用）：

```
{{Referrer name}} referred me to this opening; referral code: {{code}}.
```

## 三、跟进邮件模板（投递后 7–10 天无回音时用）

**中文**
```
主题：跟进｜应聘{{职位}}｜{{姓名}}

{{称呼}}您好：
我在{{投递日期}}投递了贵司「{{职位}}」，想跟进一下进展。
我对这个岗位依然很感兴趣，如有需要补充的材料我可以随时提供。谢谢！

{{姓名}} ｜ {{电话}}
```

**English**
```
Subject: Follow-up — {{Position}} application ({{Name}})

Dear Hiring Team,
I applied for the {{Position}} role on {{date}} and wanted to follow up on my application.
I remain very interested and am happy to provide any additional information.
Thank you for your time.

Best regards,
{{Name}} | {{Phone}}
```

## 四、投递前检查清单

- [ ] 附件是**针对本 JD 优化**的版本（不是通用版）
- [ ] 附件文件名规范：`姓名-公司-职位-简历.pdf`
- [ ] 正文里的岗位名与 JD 完全一致
- [ ] 收件人 / 抄送正确（内推人要不要抄送）
- [ ] 语言与公司/岗位匹配（大陆中文、香港/海外英文）
- [ ] 已把你确认过的正文原样粘贴（不即兴改动）
