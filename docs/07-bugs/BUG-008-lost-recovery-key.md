# BUG-008：恢复密钥遗失导致跨端同步无法继续

## 级别

P1。

## 现象

设备没有本地恢复密钥，但云端已有密文。原实现正确阻止覆盖，却没有可恢复的新同步空间，也没有口令保护的恢复包。

## 根因

恢复密钥仅存设备本地；同步记录没有空间隔离字段，因此无法同时保留旧密文与安全启动新的同步集合。

## 修复

引入 `sync_spaces`、客户端恢复包和 `sync_space_id`。旧密文进入非活动 legacy 空间；新活动空间可由恢复口令在另一设备解锁。

## 验证与限制

单元测试覆盖恢复包往返与错误口令，构建通过。迁移部署后需在 iPhone、Mac 及网页分别验证一次解锁与同步。恢复口令不上传；遗失全部设备密钥与恢复口令时，任何系统均无法解密资料。
