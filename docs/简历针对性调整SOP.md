# 简历针对性调整 SOP（跟着岗位需求改侧重）

> 目标：每份投递都用「最贴合 JD」的简历版本，提高初筛通过率。
> 底线：只改**呈现顺序与措辞侧重**，绝不改动任何事实。

## 流程（每次投递执行一遍）

### 1. 拆解 JD
把职位描述拆成：**必选要求**（硬门槛）与**加分项**，提取关键词与技能清单（按 JD 里出现的频次/权重排序）。

### 2. 证据映射
逐条对照你简历里的事实证据，产出匹配表：
`JD 要求 X → 你的证据 Y（在哪一段）→ 匹配度 高/中/低`

### 3. 调整侧重（只动呈现）
- **个人摘要**：按 JD 重写定位句——点出目标岗位方向 + 最相关的核心技能组合 + 年限/行业，一句话让 HR 对上号。
- **工作经历**：重排 bullet 顺序，把与 JD 最相关的成果提到最前；用 JD 的关键词说法改写描述（例如 JD 写 "high-throughput"，原文 "高并发" → 用对方语言），**数字与事实不变**。
- **技能区**：按 JD 的权重重排；与岗位无关的技能组折叠或后置。
- **项目**：优先展示与 JD 匹配的项目，无关项目精简。
- **教育 / 证书 / 语言**：一般不动；JD 明确要求某证书/语言时提前到显眼位置。
- **版式**：保持一页以内；若原件是 PDF 且无可编辑版，我会给出「可直接替换的文本块」+ 排版建议。

### 4. 给你看改动说明
交稿前先给你一份简洁对照：**改了什么、为什么改**（摘要改写、bullet 顺序、技能排序、去掉了哪条无关内容）。你不满意就继续改。

### 5. 定稿存档
- 命名：`姓名-公司-职位-定制v1.pdf`（版本号随修改递增）
- 原件与定制版分开放：`profile/resume/01-原件/` 与 `profile/resume/02-定制/<公司>-<职位>/`
- 每版配一份 `改动说明.md` 留在同目录
- 定稿后上传到投递台网站「我的简历」并标注版本，台账里记录用的是哪个版本

## 硬规则（不会越过的红线）

1. **不编造**：不新增经历、公司、时间、数字、奖项、技能。
2. **不夸大**：不把「参与」改成「负责」，不把 2 年写成 3 年。
3. **时间线一致**：只调顺序，不改起止时间。
4. **原件永远保留**：定制版是独立文件，原件不动。
5. **先确认后使用**：每份定制版都给你过目并确认，才用于投递。

## 诚实兜底
JD 里有些要求你确实没有证据支撑时：不硬凑、不虚构。我会明确标出「这条不匹配」，并建议替代策略（如用可迁移能力表述、投递前是否需要补经历/证书），由你决定。

## 每份定制版的检查清单
- [ ] JD 必选要求是否逐条有对应证据（无则已如实标注）
- [ ] 摘要一句话点出 JD 关键词
- [ ] 每条经历最前的 bullet 是否贴 JD
- [ ] 技能顺序是否对齐 JD 权重
- [ ] 未新增/改动任何事实（时间、数字、公司、头衔）
- [ ] 改动说明已给你确认
- [ ] 文件已存档（原件/定制分目录），台账已记录版本
