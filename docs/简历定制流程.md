# 简历定制流程（按 JD 调侧重，中英文双版本）

## 一、事实来源（不可改动）
- 原件：`profile/resume/01-原件/`（中文 + 英文的 Word 源文件与 PDF）
- 事实库：`profile/profile.json`（中英双版本事实，含待确认差异清单）
- **红线**：只调整顺序、措辞与侧重；不新增/修改经历、时间、数字、公司、头衔

## 二、定制生产（一条命令）
```bash
PY=/Users/cc/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3
$PY scripts/build_resume.py --profile profile/profile.json --lang zh --out /tmp/cv-zh.html --pdf /tmp/cv-zh.pdf --spec /tmp/spec.json
$PY scripts/build_resume.py --profile profile/profile.json --lang en --out /tmp/cv-en.html --pdf /tmp/cv-en.pdf --spec /tmp/spec.json
```

## 三、spec.json 可调项
```json
{
  "headline": "按 JD 重写的一句话定位（放在姓名下方）",
  "order_exp": ["bocom", "beichen", "boc", "putuo"],
  "limit_bullets": {"bocom": 4, "beichen": 3, "boc": 2, "putuo": 2},
  "limit_activity_bullets": 1,
  "sections": ["education", "experience", "projects", "skills"],
  "skills_order": ["office", "programming", "design"],
  "emphasize": ["数据分析", "Python", "Excel"]
}
```
- `order_exp` / `limit_bullets`：把与 JD 最相关的经历和 bullet 提前、多留
- `emphasize`：命中关键词自动加粗（不改变事实）
- `skills_order`：技能按 JD 权重重排

## 四、输出与质检
1. 生成中英文各一版（默认都控制在 **1 页**）
2. 质检项：页数 = 1、关键信息齐全、**PDF 文字层可被 ATS 正确解析**
3. 交付路径：`profile/resume/02-定制/<公司>-<职位>/`

## 五、字体与 ATS 注意（重要）
- 中文字体必须用 **STHeiti / Arial Unicode MS**。
  PingFang、Songti 会让 PDF 文字层把「香港」映射成异体码位「⾹港」，ATS 解析关键词时会漏匹配。
- 生成管线：HTML → Chrome 无头打印 PDF（文字层标准、1 页可控）。
- 原始 Word 设计版仍保留；若某家公司偏好原版式，可走"改 docx → Word 导出 PDF"路线
  （`scripts/docx_tailor.py` 支持跨 run 保留格式替换）。
