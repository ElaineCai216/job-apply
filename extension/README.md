# 投递助手 · 浏览器扩展（Chrome / Edge）

**你把岗位链接丢进来，它告诉你怎么投——邮件类直接写好邮件，官网类自动填表。**

## 安装（3 步，只需一次）

1. 打开 `chrome://extensions`（Edge 用 `edge://extensions`）
2. 右上角开启**开发者模式**
3. 点**加载已解压的扩展程序** → 选择本 `extension` 文件夹

> 改了代码后，回到扩展页点一下刷新图标即可生效。

## 一次性设置（30 秒）

打开 `https://elainecai216.github.io/job-apply/` 时，扩展会在浏览器本地与网页双向同步岗位线索、投递记录和设置。同步不经过服务器；网页和扩展需要使用同一个 Chrome / Edge 浏览器配置。

点扩展图标 → 展开底部**「我的资料」**→ 填写：姓名、微信、学校、专业/学位、毕业时间、手机、邮箱，以及**邮件要点（每行一条）**→ 保存。
之后所有邮件草稿和表单填写都会自动带上这些信息。

## Apply Desk 2.0 协议

- `APPLYDESK_CAPTURE_JOB`：抓取当前 JD 并交给工作台。
- `APPLYDESK_GET_APPROVED_MATERIALS`：读取已审核材料。
- `APPLYDESK_SAVE_FORM_DRAFT`：保存表单草稿和答案。
- `APPLYDESK_MARK_READY_FOR_REVIEW`：标记为最终确认前待审核。
- 扩展不提供自动提交或自动发送邮件的消息接口。

## 日常用法：打开岗位页面 → 点扩展图标

扩展会自动判断**投递方式**并显示在顶部：

| 判定结果 | 含义 | 你可以做什么 |
|---|---|---|
| 🟢 **邮件投递** | JD 里有投递邮箱，或页面是 mailto 链接 | 点**生成邮件草稿** → 自动写好主题+正文 → 复制，或点**打开邮件客户端**直接发送 |
| 🔵 **官网表单** | 页面有申请表单 | 点**填入表单**（自动填姓名/邮箱/电话/所在地）→ 检查后提交；简历用 Codex 定制的版本 |
| 🟢 **平台内投递** | JobsDB / JIJIS / LinkedIn / BOSS 等 | 在平台内完成申请，可先用「复制任务包」让 Codex 定制简历 |
| 🟡 **需人工确认** | 没识别到邮箱或表单 | 点**复制任务包**发给 Codex（我），我来判断 |

## 其他按钮

- **保存线索**：把这条岗位存进扩展，可**导出 JSON** 导入投递台网站「岗位线索」页
- **复制任务包**：把公司/职位/JD/链接打包成文本发给 Codex → 我出定制中英文简历 + 匹配度分析
- **填入表单**：自动填基础字段（只填空白，不改你已填的内容）

## 支持识别的渠道

公司官网 / Workday / SAP SuccessFactors / Greenhouse / Lever / Ashby / JobsDB / JIJIS / LinkedIn / BOSS 直聘 / 国内招聘平台 / 小红书 / 共享文档（腾讯文档、飞书、Google Docs、Notion 等）

## 权限说明

| 权限 | 用途 |
|---|---|
| `<all_urls>` | 在招聘页面读取岗位信息、识别投递方式、填入基础字段 |
| `storage` | 线索与资料只存本机浏览器 |
| `clipboardWrite` | 复制邮件草稿 / 任务包 |
| `contextMenus` | 页面右键菜单抓取 |
| `downloads` | 导出线索 JSON |

## 已知限制

- **邮件不会自动发送**：扩展只生成草稿，发送由你完成（邮箱凭据不在扩展里）
- **提交按钮不自动点**：官网表单会自动填，但最终提交由你确认（投出去不可撤回）
- 微信群内容无法读取：请把文字复制给我，或发群里的链接
- 需要登录才能看的共享文档，能否读取取决于你的浏览器登录态
