# 投递助手 · 浏览器扩展（Chrome / Edge）

配合"投递台"使用的求职助手：**一键抓岗位 JD → 存线索 → 生成给 Codex 的任务包 → 快速填表**。

## 安装（3 步，只需一次）

1. 打开浏览器扩展页：Chrome 输入 `chrome://extensions`（Edge 输入 `edge://extensions`）
2. 打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序** → 选择本 `extension` 文件夹

装好后工具栏会出现红色「投」图标，可固定到工具栏。

## 使用

**① 抓岗位**
在任意岗位页面点扩展图标 → 自动读取本页的**公司 / 职位 / 渠道 / JD 正文** → 核对后可改 → **保存线索**。
也可以直接在页面上**右键 → 用投递助手抓取本页岗位**。

**② 生成任务包**
点 **复制任务包** → 粘贴给 Codex（我）→ 我按 JD 产出**中文 + 英文定制简历**、**投递邮件正文**、匹配度分析。

**③ 快速填表**
先在扩展底部「自动填表资料」里填一次姓名 / 邮箱 / 电话 / 所在地 / LinkedIn / GitHub；
之后在申请表单页点 **填入表单**，自动填好基础字段（只填空字段，不动你已填的内容）。**最终提交仍由你确认。**

**④ 备份**
**导出 JSON** 备份所有线索；线索与填表资料都存在本机浏览器，不上传任何服务器。

## 支持的页面

- 公司官网 / Workday / SAP SuccessFactors / Greenhouse / Lever / Ashby
- JobsDB、JIJIS、LinkedIn、BOSS 直聘、国内招聘平台
- 小红书网页版
- 共享文档：腾讯文档、飞书、Google Docs、Notion、石墨、语雀

## 权限说明

| 权限 | 用途 |
|---|---|
| `<all_urls>` | 在招聘页面读取岗位信息、填入基础字段 |
| `storage` | 线索与填表资料只存本机浏览器 |
| `clipboardWrite` | 复制任务包 |
| `contextMenus` | 页面右键菜单抓取 |
| `downloads` | 导出线索 JSON |

## 已知限制

- **微信群内容无法读取**（微信不开放接口）：请把文字复制给我，或发群里的链接（链接我可以读）。
- 需要登录才能看的共享文档，能否读取取决于你的浏览器登录态。
- 自动填表只处理基础字段，不点击提交按钮。
